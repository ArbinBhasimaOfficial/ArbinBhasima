ここに、Web 開発(かいはつ)で よく 使(つか)われる 基本(きほん)的(てき)な HTML タグ(たぐ)の 分類(ぶんるい)と、 現代(げんだい)の Web 開発(かいはつ)（セマンティック HTML）で 不可欠(ふかけつ)な タグ(たぐ)の 一覧(いちらん)を まとめました。

基本(きほん) タグ(たぐ)の 分類(ぶんるい)
  文書(ぶんしょ) 構造(こうぞう):

    <!DOCTYPE html>: ブラウザ(ぶらうざ)に 文書(ぶんしょ) 形式(けいしき)を 宣言(せんげん)する。

    <html>: ルート(るーと) 要素(ようそ)の ラッパー(らっぱー)。

    <head>: メタデータ(めたでーた)、 タイトル(たいとる)、 外部(がいぶ) スクリプト(すくりぷと)や スタイル(すたいる)への リンク(りんく)を 収める(おさめる)。

    <body>: 画面(がめん)に 表示(ひょうじ)される すべての コンテンツ(こんてんつ)を 収める(おさめて)。

  テキスト(てきすと) と 見出し(みだし):

    <h1>–<h6>: 見出し(みだし) タグ(たぐ)。<h1>（ 最(もっと)も 重要(じゅうよう)）から <h6>（ 階層(かいそう)が 最(もっと)も 低い(ひくい)）まで 構造(こうぞう) 化(か)される。

    <p>: テキスト(てきすと) 段落(だんらく)を 表す(あらわす) ブロック(ぶろっく) 要素(ようそ)。

    <span>: 改行(かいぎょう)を 発生(はっせい)させずに 特定(とくてい)の テキスト(てきすと) 部分(ぶぶん)に スタイル(すたいる)を 適用(てきよう)するための インライン(いんらいん) コンテナ(こんてな)。

  レイアウト(れいあうと) と コンテナ(こんてな):

    <div>: 要素(ようそ)を グループ(ぐるーぷ) 化(か)し、 スタイル(すたいる)や 構造(こうぞう)的(てき) レイアウト(れいあうと)を 適用(てきよう)するための 汎用(はんよう) ブロック(ぶろっく) レベル(れべる) コンテナ(こんてな)。

    <hr>: 水平(すいへい) 線(せん)。 テーマ(てーま)の 切り替え(きりかえ)や 区切り(くぎり)を 作成(さくせい)する。

    ナビゲーション(なびげーしょん) と メディア(めでぃあ):

    <a>: アンカー(あんかー) タグ(たぐ)。href 属性(ぞくせい)を 使用(しよう)して ハイパーリンク(はいぱーりんく)を 作成(さくせい)する。

    <img>: src 属性(ぞくせい)と alt 属性(ぞくせい)を 使用(しよう)して 画像(がぞう)を 埋め込む(うめこむ)。

  リスト(りすと):

    <ul>: 順序(じゅんじょ)の ない リスト(りすと)（ 箇条(かじょう) 書き(がき)）。

    <ol>: 順序(じゅんじょ)の ある リスト(りすと)（ 番号(ばんごう) 付き(つき)）。

    <li>: リスト(りすと) 項目(こうもく)（<ul> または <ol> の 内部(ないぶ)に 配置(はいち)する）。

  フォーム(ふぉーむ) と ユーザー(ゆーざー) 入力(にゅうりょく):

    <form>: 対話(たいわ)型(がた) フォーム(ふぉーむ) コントロール(こんとろーる)の ラッパー(らっぱー)。

    <label>: フォーム(ふぉーむ) 要素(ようそ)の キャプション(きゃぷしょん)を 定義(ていぎ)する（for 属性(ぞくせい)を 使用(しよう)）。

    <input>: 柔軟(じゅうなん)な 入力(にゅうりょく) フィールド(ふぃーるど)（ テキスト(てきすと)、 チェックボックス(ちぇっくぼっくす)、 ラジオボタン(らじおぼたん)、 パスワード(ぱすわーど)など）。

    <button>: クリック(くりっく) 独立(どくりつ) ボタン(ぼたん)（ フォーム(ふぉーむ) 内外(ないがい)で 使用(しよう)）。

  テーブル(てーぶる)（ 表(ひょう)）:

    <table>: 表(ひょう) 形式(けいしき) データの コンテナ(こんてな)。

    <tr> / <th> / <td>: テーブル(てーぶる)の 行(ぎょう)、 ヘッダー(へっだー) セル(せる)、 データ(でーた) セル(せる)。

  追加(ついか)すべき 必須(ひっす)の セマンティック(せまんてぃっく) タグ(たぐ)
    現代(げんだい)の 慣用(かんよう)的(てき)な HTML では、<div> だけに 頼る(たよる)のではなく セマンティック(せまんてぃっく) タグ(たぐ) を 重視(じゅうし)する。 これにより、 検索(けんさく) エンジン(えんじん)や スクリーンリーダー(すくりーんりーだー)に対して 構造(こうぞう)の 意味(いみ)が 明確(めいかく)になる。

    <header>: ページ(ぺーじ)や セクション(せくしょん)の ナビゲーション(なびげーしょん)や ロゴ(ろご)を 導入(どうにゅう)する。

    <nav>: ナビゲーション(なびげーしょん) リンク(りんく)の 専用(せんよう) ブロック(ぶろっく)。

    <main>: ドキュメント(どきゅめんと)の 中心(ちゅうしん)となる 固有(こゆう)の コンテンツ(こんてんつ)を 囲む(かこむ)。

    <section>: 関連(かんれん)する コンテンツ(こんてんつ)を テーマ(てーま) ごとに まとめる。

    <article>: 独立(どくりつ)して 再(さい) 利用(りよう) 投影(とうえい) 可能な コンテンツ(こんてんつ)（ ブログ(ぶろぐ) 記事(きじ)や ニュース(にゅーす) 項目(こうもく)など）を 囲む(かこむ)。

    <aside>: 周辺(しゅうへん) コンテンツ(こんてんつ)に 関連(かんれん)する 補足(ほそく) 情報(じょうほう)（ サイドバー(さいどばー)など）を 収める(おさめる)。

    <footer>: ページ(ぺーじ) 下部(かぶ)の 著作(ちょさく) 権(けん)、 クレジット(くれじっと)、 連絡(れんらく) 先(さき) リンク(りんく)を 定義(ていぎ)する。
